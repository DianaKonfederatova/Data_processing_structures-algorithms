# Структуры и Алгоритмы Обработки Данных (1-ый курс, 1-ый семестр)

Решения лабораторных работ по СиАОД. 

## 1-ый курс
Курс **«Структуры и Алгоритмы Обработки Данных»** охватывает:
- Базовые и продвинутые алгоритмы сортировки
- Структуры данных: массивы, списки, деревья, хеш-таблицы
- Методы поиска и индексации
- Анализ сложности алгоритмов
- Анализ времени сортировок по различным видам массивов
